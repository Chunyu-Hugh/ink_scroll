# 数字媒体艺术的交互，与我们的位置

> 这份文档回答三个问题：**艺术家实际在用哪些交互**（不是传感器清单，是艺术手法）、**中外谁在做、做到什么程度**、**「墨卷」差在哪、怎么追**。
> 所有具名作品都附了实际抓取过的 URL（§7 编号），抓不到 / 只抓到标题的，在表里明写 **未经核实**。
> 范围：只讨论"观众的动作 → 作品的响应"这条回路；纯放映、纯雕塑不进表。

**一句话结论**：国际上成熟的交互作品，几乎都不靠"传感器多"，而靠**一个输入 → 一个不可替代的物理后果**（心跳点亮一排灯、影子变成幕布、雨在你头上停住）。「墨卷」已经有很好的输入广度（42 个模态）和一个漂亮的核心隐喻（墨下藏色），但**输出侧只有一块屏幕、一个光圈、一个观众**——差距不在输入端，在"世界"这一端。

## 1 · 交互的谱系（按艺术家的用法分类，不按传感器分类）

### 1.1 身体 / 姿态
**定义**：观众不需要拿任何东西，身体本身就是输入；作品读的是轮廓、重心、速度，而不是"指令"。[1][2][8]
- Myron Krueger《Videoplace》1970s–，美国 —— 摄像头把观众剪影放进共享虚拟空间，屏幕上的图形与你的影子互相反应。[1]
- David Rokeby《Very Nervous System》1986–1990，加拿大 —— 摄像头 + 图像处理，身体动作直接合成音乐，获 1991 年 Ars Electronica 交互艺术优异奖。[2]
- teamLab《Flowers and People, Cannot be Controlled but Live Together》2010s–，日本 —— 人停下，花就开得久；人走过，花瓣被打散。[8]

### 1.2 触摸与物体
**定义**：观众碰一个**实体**——木头、陀螺、金属板、一张卡片；触感本身就是内容的一部分。[6][15][5]
- Daniel Rozin《Wooden Mirror》1999，以色列/美国 —— 830 块木片 + 830 个舵机 + 摄像头，你站在它面前，它用木片把你打成像素。[6]
- Myriam Bleau《Soft Revolvers》2014，加拿大 —— 旋转陀螺的角速度驱动音序，手感即节奏。[15]
- Rafael Lozano-Hemmer《Pulse Room》2006 —— 手握住接口，心跳点亮离你最近的那盏灯。[5]

### 1.3 声音与呼吸
**定义**：把"说不出口的东西"（气息、音高、静默）变成可见的量；关键不是识别，是**让不可见变可见**。[2][16]
- David Rokeby《Very Nervous System》—— 声音不是配乐，是身体的直接延伸。[2]
- Dmitry Morozov（vtol）《Triangulator》—— 声音雕塑：机械结构把声音变成空间中的三角测量。[16]
- （对照）「墨卷」的 `audio` / `breath` / `clap` / `blow` 已经在做同一件事，缺的是"声音的空间化"，见 §4。

### 1.4 光与影
**定义**：光不只是输出，光的**遮挡**才是输入；影子是观众留下的唯一痕迹。[4][9][5]
- Lozano-Hemmer《Body Movies》2001 —— 400–1800 ㎡ 的广场上，机器人投影机把上千张本地路人肖像投出来，**但只在路人的影子里才看得见**。[4]
- Kimchi and Chips《Light Barrier》2014，韩国/英国 —— 数百万条校准光束在空气里交叉，凝结成可以穿行的"光体积"。[9]
- Lozano-Hemmer《Pulse Room》—— 300 盏 300W 白炽灯，用明灭写心跳。[5]

### 1.5 数据与算法
**定义**：输入不是观众，是**世界的数据流**（卫星、河流、影像库）；观众是读者，不是操作者。[11][13][14][20]
- onformative《Meandering River》2018，德国 —— 河流改道的算法推演变成视听装置，人看到的是"地质时间"。[11]
- Quadrature《Classified Orbits》—— 抓取约 50 个未编目的太空物体轨道，记录数周，用激光刻在黑阳极氧化铝板上。[13]
- 郭锐文（Raven Kwok）《5158, But Figurative》2024，中国 —— 摄像头画面的亮度决定龙形曲线每一段的折叠次数，Processing 写成。[20]

### 1.6 网络与远程
**定义**：两个物理空间被一条链路焊在一起，**距离本身是材料**。[3]
- Paul Sermon《Telematic Dreaming》1992，英国 —— 两张相隔很远的床，ISDN 实时视频把对方投到你的床上，你和一个不在场的人同床。[3]
- （对照）「墨卷」的 `phone`（每部手机一盏灯）+ `server.py` 中继，已经是这个结构的弱化版：远程在场，但没有"身体"。

### 1.7 生物信号
**定义**：心跳、皮电、脑波、表情——**观众无法伪装的数据**，作品因此获得"诚实"。[5][17]
- Lozano-Hemmer《Pulse Room》—— 心跳被记录、排队、推进；灯阵是一部"最近 300 个人的心脏合奏"。[5]
- 费俊团队《情绪剧场3.0》2025，中国 —— AI + 情感计算实时读取愉悦/好奇/焦虑，因人而异地生成疗愈性声音与画面。[17]

### 1.8 环境与天气
**定义**：把"天气"搬进室内，或把观众搬进别人的感官；尺度即震撼。[10][12]
- Random International《Rain Room》2012，英国 —— 屋里在下雨，你走到哪里，雨就在哪里停。[10]
- Marshmallow Laser Feast《In the Eyes of the Animal》2015（**年份未经核实**），英国 —— VR 把观众变成森林里的其他物种，看见人看不见的世界。[12]

### 1.9 观众之间的协作
**定义**：作品的作者是"人群"；单人玩不起来，多人才能成立。[3][4][8]
- Paul Sermon《Telematic Dreaming》—— 必须有两个（异地）人。[3]
- Lozano-Hemmer《Body Movies》—— 影子要够多才铺满广场，陌生人被迫互相配合站位。[4]
- teamLab—— 作品无边界，别人的存在会改变你眼前的花。[8]

### 1.10 时间与记忆
**定义**：作品记得你来过；时间被压缩（数周 → 一秒）或拉长（一次心跳 → 一排灯）。[5][13][22]
- 《Pulse Room》—— 每次新的心跳把整排记录往前推一格，最后一个人把第 300 个人挤掉。[5]
- Quadrature《Classified Orbits》—— 数周的轨道被压成一道银线。[13]
- 缪晓春《虚拟最后审判》2006，中国 —— 用自己一个人的数字化身，重演米开朗基罗《最后的审判》里所有人。[22]

### 1.11 游戏与仪式
**定义**：给观众一个**角色**和一套规则，让他愿意在作品里"待着"；或给一个仪式，让他知道该做什么。[1][24][25]
- Myron Krueger《Videoplace》—— 最早的"身体即手柄"，没有手柄。[1]
- 陆扬《妄念曼陀罗》2015（年份**未经核实**），中国 —— 用 3D 扫描的自我形象进入宗教图像与神经科学的混合空间，游戏引擎语法。[25]
- 邱志杰《破冰》（南京长江大桥计划，2009）—— 21 件子作品构成一个可穿行的"沉船"现场，观众按现场动线完成一次仪式。[24]

### 1.12 机器作为合作者
**定义**：机器不是工具，是**有立场的另一方**——它会看你、拒绝你、误解你。[7][12][14][18]
- Golan Levin《Opto-Isolator》2007，美国 —— 一只机械眼，你盯着它，它才回看你；**单向凝视**被做成延迟。[7]
- Refik Anadol《Machine Hallucination》2019 —— 城市影像数据集训练出的潜空间影像，铺满建筑内壁，机器"梦见"这座城市。[14]
- 李世奇《人工神经雅集》2025，中国 —— LED 波浪屏上，神经网络学习中式审美后重演古画。[18]

## 3 · 他们共有的手法（12 条，可以直接抄）

| 手法 | 具体做法 | 谁在用 |
|---|---|---|
| **观众即材料** | 不画人，用人的轮廓/影子/心跳当图像本身 | #4 #5 #6 #2 |
| **极端尺度** | 要么 1800 ㎡（Body Movies），要么 300 盏灯塞满房间（Pulse Room） | #4 #5 #9 |
| **慢交互** | 响应延迟 0.5–3 秒，逼你放慢；不是"跟手" | #7 #10 #6 |
| **一次只做一件事** | 一个作品只有一个输入通道，把它做到极致 | 全部 |
| **简单输入，深刻体验** | 输入是"站着""心跳""下雨"，输出却不可替代 | #5 #10 #4 |
| **把数据变成身体** | 卫星轨道、河流、心跳 → 可触摸的物理量 | #13 #5 #11 |
| **镜像与延迟** | 你看到的是"几秒前的你"或"别人看到的你" | #6 #7 |
| **多人同步** | 必须两个人/一群人才能成立 | #3 #4 #8 |
| **作品记得你** | 队列、档案、被挤掉的旧记录 | #5 #13 |
| **无界面** | 没有按钮、没有说明牌，靠空间暗示 | #4 #10 #2 |
| **让技术可见** | 把传感器/机械结构露出来（舵机、灯泡、投影机） | #6 #5 |
| **可玩 vs 沉思** | 前者给规则（游戏），后者给氛围（雾、雨、光）——两者不混 | #1 可玩 / #10 沉思 |

### 4.2 真正缺的（对着 §2 那张表一条条比）

| 缺什么 | 具体表现 | 别人怎么做到了 |
|---|---|---|
| **空间尺度** | 最大是一块屏幕/一面墙；没有 400–1800 ㎡ 的场地级作品 | #4 #9 |
| **声场** | 只有一个 generative pad，没有多声道/空间化 | #2 #16 |
| **真实材质** | 输出全是像素，没有木头、灯泡、水、雾 | #6 #5 #10 |
| **多人身体** | `spots()` 最多 6 盏灯，**没有人数、身份、在场、z** —— atlas 自己承认这是"一半模态只能硬塞 x,y 的根因" | #3 #4 #8 |
| **长期运行** | 没有 24h+ soak 测试、没有重启自愈、没有运行日志 | 所有展陈作品 |
| **策展叙事** | 没有作品署名/展签/版本号/展览履历（哪怕是自述） | 全部 |
| **深度** | 契约无 z；MediaPipe 的 478/21 个 3D 关键点被压成 2D 用掉 | #9 #12 |
| **预算纪律** | CDN 已 5 个，超出自己定的"≤4"硬规则 | [26] §0 |

## 6 · 五个最值得模仿的作品（抄机制，不抄外观）

1. **《Pulse Room》** —— 抄它的**队列结构**：一个输入口，N 个输出位，新输入把旧记录**整体推一格**，末尾被挤掉。
   → 落到代码：`spots()` 环形缓冲 + 每盏灯 `ttl`。"墨卷"可以变成"最后 30 次触摸留在墙上，第 31 次把第 1 次推走"。这是**零成本获得"记忆"**的唯一办法。
2. **《Body Movies》** —— 抄它的**遮罩反转**：不追踪人，把人的**影子**当遮罩，内容藏在影子里。
   → 落到代码：摄像头帧差已有（`motion` 模态），把"变化像素"从**取质心**改成**当 mask**，一行思路的转变，换来"你的身体是画框"。注意：它不需要关键点模型，**比 MediaPipe 便宜两个数量级**。
3. **《Wooden Mirror》** —— 抄它的**分辨率限制**：830 个执行器就是 830 像素，**限制本身就是美学**。
   → 落到代码：把点云从 1 万点降到 48×48 网格再做墨色量化；"低分辨率"是风格，不是妥协。
4. **《Rain Room》** —— 抄它的**局部豁免**：不是"加一个效果"，而是在一个连续场里挖一个"被豁免的区域"。
   → 落到代码：「墨卷」的揭色机制本质相同，缺的是**边界锐度 + 延迟 + 环境声**三件事：把光圈边缘从"羽化"改成"硬边 + 0.3s 延迟 + 雨声随距离衰减"，立刻从"滤镜"变成"天气"。
5. **《Opto-Isolator》** —— 抄它的**单向凝视 + 延迟**：机器先看你，你回看它才回应；**不跟手**制造主体性。
   → 落到代码：给光圈的跟随加 200–600ms 的"犹豫"和一个周期性的"眨眼"中断（`dwell` 模态已有计时器，复用它）。这是**用延迟换人格**，成本近乎零。
