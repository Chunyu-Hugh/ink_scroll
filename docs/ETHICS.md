# 身体数据与伦理 · Body data & ethics

> 生物信号（心率、脑电、肌电、皮电、眼动、呼吸）能做出最动人的作品，
> 也最容易被做成一门**未经同意就拿走别人身体数据**的生意。这一页是硬规矩。

## 三条底线

1. **不采集，只感受**
   我们的所有生理输入都在**浏览器内实时处理并立刻丢弃**：不落盘、不上传、不进数据库。
   页面里没有账号、没有分析、没有埋点。关掉标签页 = 数据消失。

2. **不推断身份**
   心率用于让光圈呼吸，**不用于**判断情绪、健康、年龄、性别、注意力或任何个人属性；
   不做人脸识别、不做身份关联。`pulse` 只输出一个数字（BPM），`ble` 只输出一条曲线。

3. **不保存，不重放**
   没有"回放某个人的心跳"这种功能。作品可以有记忆（墨迹、长曝），
   但记的是**光走过的痕迹**，不是**人**。

## 现场怎么做（给布展的人）

| 场景 | 要求 |
|---|---|
| 摄像头模式（手势/面庞/动影/眨眼） | 入口处**明示**"本作品使用摄像头，画面只在本机处理，不录制、不上传" |
| 麦克风模式（声音/呼吸/吹墨/拍手/口哨） | 同上；建议在展签上写"只取音量与音高，不录音" |
| 生物信号（心率带/EEG） | **观众自己佩戴自己的设备**；我们不提供、不代管、不统一采集 |
| 多人（手机众光） | 观众扫码**自愿加入**，随时可关页面退出；不收集手机号/位置 |
| 未成年人 | 摄像头与生理信号模式建议 16+ 或需监护人陪同 |

## 技术上我们怎么保证（不是口号）

- 摄像头/麦克风数据只经过 `getUserMedia` 的本地流，页面没有任何上传图像的代码路径
  （`index.html` 里所有 `fetch` 只发 JSON 状态，`grep` 可查）
- 服务器 `server.py` **不存任何画面**，只在内存里放最后一条状态（进程退出即消失）
- 没有 Cookie / localStorage 只存语言偏好（`ink-lang`）
- 需要关闭时：退出画面即释放摄像头轨道（`stop()` 已断言）

## 可以公开说的话

> 本作品不使用面部识别，不记录影像与声音，不推断你的任何个人属性。
> 摄像头与麦克风只在本机内存里换算成一个光圈的坐标，关闭页面即消失。

## 不能做的事（写死）

- ❌ 把观众的心率/表情上传到任何服务器
- ❌ 用生理数据做"情绪识别""注意力统计""人群画像"
- ❌ 未经告知录制观众影像用于宣传
- ❌ 收集手机号、微信号、地理位置
- ❌ 让生物信号成为**唯一**交互入口（拒绝授权也必须能玩）

## 如果将来真的要统计

只允许**聚合到无法回溯个人**的粒度（例如"今天共有 213 人靠近过"），
且必须在展签上公开统计口径与用途。默认不做。
