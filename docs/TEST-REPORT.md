## 一、审核发现的阻塞性问题（已修）

## 二、交互层面的缺失（已新增）

原仓库的 6 个模态里，**真正零门槛可用的只有 `mouse` 一个**：手电筒要手电、手势要模型+摄像头、
眼动要打印 ArUco 标记、手机要中继（且文件缺失）、IR 要硬件。

新增 5 个**纯浏览器、无需任何外设**的模态：

| 模态 | 输入 | 为什么值得加 |
|---|---|---|
| **自动展卷** `auto` | 无 | 展厅/展台/路人：不碰也能看到东西在发光，形成"招徕"循环 |
| **声音 · 吟诵** `audio` | 内置麦克风 | 基频→X、音色→Y、响度→半径、瞬态→泼墨。「吹墨/吟诵」的国画母题 |
| **动影 · 皮影** `motion` | 内置摄像头 | **零模型、零下载**的帧差质心。影子掠过绢面→彩色显形（皮影戏） |
| **面庞 · 头姿** `face` | 内置摄像头 | MediaPipe FaceMesh：鼻尖移光、张嘴放大。**不需要打印标记**也能"用头玩" |
| **倾斜 · 掌中** `tilt` | 手机陀螺仪 | 手机上最自然的一维输入；进入时自动取零点，`C` 重设 |

并把 `mouse` 升级为 **指针 · 触屏**：拖动揭示、双指捏合改光圈、双击换场景、长按留痕、**压感笔 → 笔锋**。

## 三、可访问性与体验修复

- canvas：`role="img"` + 动态 `aria-label`（随场景更新）
- 所有状态变化（模式/场景/风格/存图/暂停）通过 `role="status" aria-live="polite"` 播报
- 帮助面板：`role="dialog" aria-modal="true"`、**焦点陷阱**、Esc/背景关闭、关闭后归还焦点、打开时 canvas `aria-hidden`
- `prefers-reduced-motion: reduce` → 关掉粒子shimmer；另设 `P` **静观**（真正暂停，WCAG 2.2.2）
- 焦点环保留（`focus-visible` 全部可见）
- 光圈环加中性深色描边：浅色纸本与深色墨线两种风格下都读得出来
- 控制栏 `role="toolbar"` + 每个按钮 `aria-label`；`aria-pressed` 反映开关状态
- iOS 不支持元素级全屏 → 明确提示而不是静默失败
- 触屏下**不再有焦点依赖**：所有功能都在控制栏/手势里

## 四、健壮性

- 摄像头：`flashlight` 用 `facingMode:'environment'`（看房间），`hand/face/motion` 用 `'user'`（看自己），失败逐级回退到 `video:true`
- 所有传感器模态失败都 `wM('mouse',{silent:true})`：**说清原因 → 落到可用状态 → 不打断画卷**
- 退出时释放摄像头轨道（`Q`/`Esc`/返回标题均验证）
- `AudioContext` 在用户手势内 `resume()`（自动播放策略）
- `wakeLock` 保持展厅屏幕常亮，`visibilitychange` 后重新申请
- 麦克风/摄像头/陀螺仪**都不是唯一通路**
- MediaPipe legacy 版本号已锁定（`0.4.1675469240` / `0.4.1633559619`），避免资产与版本错配导致白屏

## 五之二、第二轮（评测器自己长了一条断言）

加了「画面语义」这一组断言之后，它立刻抓出两个问题：

1. **离开摄像头模态时摄像头没有释放**——切到指针模式后 `str` 还活着，摄像头指示灯一直亮着，
   15% 的摄像头幽灵图层也还在往后画。这是隐私 + 电量问题。已修：`wM()` 在目标模态
   不需要摄像头时停轨道并清 `vid`。现在有断言守着（`切到非摄像头模态后摄像头已释放`）。
2. **风格亮度阈值是拍脑袋定的**——实测四风格的平均亮度是 纸本 176 / 墨线 92 / 素描 8 / 暗调 23，
   原来写的 `< 90` 对墨线这种高密度线描图根本不成立。改成相对关系（纸本 >150，墨线比纸本暗 50 以上，
   素描与暗调近黑），这才是真正有意义的约束。

另外补了三条结构性断言：核心机制（**光圈内外颜色必须不同**）、五场景指纹互不相同、
`docs/INTERACTIONS.md` 必须覆盖每一个已注册模态（文档即测试）。

## 五之三、第二批模态（21 种，按三档）

| 档 | 新增 | 说明 |
|---|---|---|
| ① 什么都不用 | `keys` 键盘、`multi` 多指、`pen` 压感笔、`dwell` 凝视停留、`breath` 吐纳、`speech` 语音、`shake` 摇一摇 | 全部用机器自带硬件；`pen`/`keys`/`dwell` 是无障碍主干 |
| ② 插个装置 | `gamepad` 手柄、`midi` MIDI | 没插装置时给一句"插上后按任意键"，不阻塞 |
| ③ 本机脚本 | `osc` | `server.py` 新增 UDP 9000 的 OSC 入口 + `POST /osc`，TouchDesigner/Max 直接发 `/spot` |

另外补了**按设备挑默认模态**（`pickDefaultMode()`）：手机→多指、大屏→自动展卷、桌面→指针。

测试从 96 涨到 **137 条**，新增一组「第二批模态」：键盘方向键必须移光而不切场景、
三根手指必须等于三盏灯、笔压 0.15→0.95 光圈至少大 1.8 倍、停住 1.4 s 必须换画、
合成加速度必须触发泼墨、假手柄摇杆必须推动光圈、假 MIDI CC1 必须改 X 轴、
以及**真的用 UDP 发一个 OSC 包**过去验证 TouchDesigner 那条路径。
